## THE TOKEN COUNTS ARE EXACT

The counts above come from DeepSeek's own tokenizer: the published
`deepseek-ai/DeepSeek-V3` `tokenizer.json`, 128,000 vocabulary entries and
127,741 merges, implemented directly because this lane holds no DeepSeek API key.
It was validated two ways over this corpus: every produced symbol exists in the
published vocabulary with zero exceptions, and decoding the produced tokens
reproduces the original text byte for byte.

For scale, against DeepSeek's published context limits: the largest piece is
75,148 tokens, which is inside the 1M context of the current `deepseek-v4-pro` and
`deepseek-flash` with more than 13x headroom, and still inside the 128K context
of the retired `deepseek-chat` and `deepseek-reasoner` models with 41 percent
headroom. The whole Master Spec as ONE file is 212,785 tokens, which also fits a 1M
context. Three pieces were kept for the Spec rather than one so that each piece
also fits a 128K context, and so that no single fetch carries more than
266,336 bytes.
