## WHY FOUR

DeepSeek's current models carry a 1M token context (`deepseek-v4-pro` and
`deepseek-flash`). The older 128K models (`deepseek-chat`, `deepseek-reasoner`)
were retired on 2026-07-24. The Master Spec is 728,257 characters, roughly
180,000 to 205,000 tokens, so the whole document fits a 1M context with room
to spare.

A single 728,257 character file would also fit that context, but a fetcher
that truncates at a few hundred kilobytes would hand a reader half the
document. Each piece here is at most 266,336 bytes, which is about 62,000 to
74,000 tokens: inside a 1M context, inside a 128K context, and inside any
reasonable fetch limit. The token figures are measured, not guessed: a live
call returned 2,222 prompt tokens for an 8,000 character slice of the Master
Spec (3.60 chars per token) and 6,858 prompt tokens for the 27,794 character
Cinema Spec (4.05 chars per token). The tokenizer measured is the provider's
own, so it is a close proxy rather than DeepSeek's exact count.
